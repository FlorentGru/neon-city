# Neon City

A cyberpunk night theme for Claude: very dark blue-violet surfaces, magenta and cyan neon accents, and an animated
backdrop of a city skyline in the rain, with flickering neon signs. *Thème ville cyberpunk : nuit, néons magenta et
cyan, pluie animée.*

- Drawn in the Claude **desktop and mobile apps** (the terminal and editors draw no theme).
- Dark mode only.
- The backdrop is a single SVG animated with CSS: no script, nothing loaded from the network. It stops moving when
  your system asks for reduced motion.
- Original artwork: no third-party logo or font.

## Install

At the prompt of a terminal session:

```
/plugin install neon-city --marketplace FlorentGru/neon-city
```

Answer `y` to add the marketplace, then pick a scope (user scope applies it to every session).

From a shell:

```bash
claude plugin install neon-city --marketplace FlorentGru/neon-city
```

In the desktop app, where `/plugin` does not run: click **+** next to the prompt box, then **Plugins**, **Add
marketplace** with `FlorentGru/neon-city`, then **Add plugin**.
